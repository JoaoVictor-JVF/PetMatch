# 🐾 PetMatch

## 💬 Descrição
O PetMatch é um projeto que recomenda o animal de estimação ideal para cada pessoa, com base em sua **personalidade**, **moradia**, **rotina** e **recursos disponíveis**.  
A proposta é promover uma adoção responsável e consciente, considerando o bem-estar do animal e a realidade do tutor.

Versão inicial — foco em cães e gatos.  
Futuras versões incluirão outros animais, respeitando a legislação brasileira.
